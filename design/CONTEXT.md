## 1. 出発点：建築資材で最もよく廃棄されるもの

**重量ベースの答えはコンクリート塊**。国交省「建設副産物実態調査」平成30年度確定値、建設廃棄物 約7,440万トンの内訳。

| 品目 | 排出量 | 構成比 | 再資源化・縮減率 |
|---|---:|---:|---:|
| コンクリート塊 | 約3,690万t | 約50% | 99%超 |
| アスファルト・コンクリート塊 | 約2,070万t | 約28% | 99%超 |
| 建設汚泥 | 約620万t | 約8% | 約95% |
| 建設発生木材 | 約550万t | 約7% | 約96% |
| 建設混合廃棄物 | 約140万t | 約2% | 約63% |

上位2品目で約8割。ただし両者はほぼ全量が再生砕石・再生アスファルト合材として循環していて、
最終処分量は全体の2.8%（212万t）まで落ちている。

**「捨てっぱなしになる」量で見ると話が変わる。** 廃石膏ボードは硫化水素の懸念から管理型処分場でしか
埋め立てられず、特に解体系はリサイクル体制・技術が確立しきっていない。建設混合廃棄物は再資源化率63%と
突出して低く、分別せずに混ぜた瞬間に木くずも石膏ボードも回収不能になる。

> ⚠️ この環境は `mlit.go.jp` などへの外部アクセスがプロキシで遮断されており、**一次PDFを開けていない**。
> 上記は検索スニペットと平成30年度確定値ベース。令和6年度（2024年度）調査が実施済みなので、
> 結果が出れば数値は更新される。ローカルなら普通に開けるはずなので裏を取ってほしい。

## 2. 「もらってくれるならあげる」＝ 負の価値の材料

成立条件ははっきりしていて、**運搬費 < 処分費** のときだけ。逆転すると「金を付けるから持って行って」（逆有償）になる。

**タダでもいらない側**（処分費だけかかる）

- 古畳（1枚1,500〜3,000円）／廃石膏ボード／アスベスト含有建材（吹付け・古いスレート屋根・Pタイル）
- 使用済みグラスウール／CCA処理された防腐土台・枕木／衛生陶器／ブロック塀・浄化槽・井戸

**「もらってくれるなら」の定番**（価値はあるが運べない）

- 庭石・灯籠・つくばい（撤去にユニックが要る。運搬費で確実に赤字＝この言葉の王様）
- 和瓦（いぶし瓦は需要があるのに1枚3kg×数千枚で運賃が価値を食う）／庭の大木／和箪笥・仏壇・ピアノ／物置・農機具

**拾う価値があるのは古材とアルミサッシだけ。** 比重が軽くて素材単価が高いものしか「もらう価値」を持たない。

**物件そのものの0円物件**は「価格0円・負債つき」。残置物処分数十万、木造30坪の解体費100〜200万、
再建築不可、私道や山林の抱き合わせ。300万で状態のマシな家を買うほうが総額で安いことが多い。
手放す側には2023年開始の**相続土地国庫帰属制度**（10年分の管理費相当を納めて国に返す）もある。

## 3. 指名された4品目を、北軽井沢で使えるか

寒冷地（1月の最低−10〜−14℃、凍上、結露）が効いて、「水に弱い」「凍る」「持ち上がる」ものが軒並み落ちる。

| 品目 | 判定 | 理由 |
|---|---|---|
| 廃石膏ボード | △ | **新築現場の端材なら◎**（もらう相手は解体屋でなく工務店）。解体品は釘穴・紙面剥離・カビでほぼ再起不能。1970〜80年代の耐火ボードはアスベスト含有品があるので築年不明品は触らない |
| 使用済みグラスウール | △ | 乾燥した袋入りの余りなら性能は落ちない。ただし寒冷地の居室断熱は暖房費と壁内結露を通じて**建物寿命に直結**するので賭ける場所ではない |
| 衛生陶器 | 洗面◎/便器△/UB× | 洗面ボウルは排水トラップだけ新品でそのまま使える。便器は**寒冷地仕様でないと冬に割れる**。ユニットバスは解体した時点で防水の取り合いが死ぬ |
| ブロック塀 | 構造× / 砕石○ | 鉄筋が切れていて強度が保証できず、寒冷地の基礎は凍結深度より深く打つ必要があるので束石代わりは論外。砕いて路盤材・雨落ち・花壇の縁なら可。1個10kgで運搬費が価値を上回るので「もともと敷地にあったものを砕く」用途に限る |

**法的な注意。** この4つはいずれも産業廃棄物なので、他人の現場から無償で引き取って運ぶのは
収集運搬の許可が絡むグレーゾーン。工務店から端材として譲り受けるか、自分の敷地の解体材を
自分の敷地で使う（自ら利用）の形にしておくのが安全。

## 4. 北軽井沢の土地について調べたこと

- 大字北軽井沢の**坪単価は1万円前後**（公示地価ベース）。別荘が約1万戸集積した成熟エリア
- 実例：プリンスラン別荘地 **100万円 / 274㎡（83坪）**、紀州鉄道 浅間高原ヴィレッジウッド **70万円 / 234㎡**
  → `spec.json` の敷地273㎡はこの274㎡の事例を下敷きにしている

**土地代が安いぶん、買ったあとが本体。**

| 項目 | 目安 |
|---|---|
| 上水道引込 | 数十万〜100万超（引込済みかで総額が変わる） |
| 浄化槽 | 設置 数十万〜100万／維持 3〜5万・年 |
| 別荘地管理費 | 年 数万〜（軽井沢の管理別荘地だと30〜50万・年の帯も）。**滞納の承継**を契約前に確認 |
| 凍結防止ヒーター | 月3,000〜5,000円（冬に使わなくてもかかる） |
| 暖房 | 10月〜GWまで必須 |

**建築確認。** 2025年4月の法改正後も、**都市計画区域外なら平屋200㎡以下（新3号）は確認申請不要**のまま。
主屋を39.75㎡＝平屋200㎡以下に収めてあるのはこれに乗るため。
ただし **長野原町が都市計画区域外かどうかは未確認**（この環境から町の資料に到達できなかった）。
→ **町の建設課に電話一本が最短。** ここが区域内だと前提が変わる。

**先に潰しておくべき地雷**

1. 別荘地の**建築協定**（最低敷地面積・外壁色・セルフビルド禁止条項がある分譲地は実在する）← セルフビルド前提だと致命傷
2. 私道共有と管理費の承継　3. 水道加入金　4. 浅間山の火山避難計画区域　5. 傾斜地の造成費

**探し先**：浅間ホーム（価格帯別ページあり）、シバタエステート、ロイヤルリゾート、ハトマークサイト。

## 5. 設計判断と、その理由

寸法は全部理由から逆算している。数値だけ見ても分からないので、対応を残す。

| 決めたこと | なぜ |
|---|---|
| 敷地 14.0×19.5m ＝ 273㎡ | 実在の分譲事例274㎡に合わせた |
| 北→南へ5%の下り | **南に下る＝浅間方向（203°）＝大開口の向き**が全部揃う地形にした |
| 平屋 39.75㎡ | 200㎡以下＝都市計画区域外なら確認申請不要の新3号に収める |
| 910グリッド 8P×6P | 石膏ボード910×1820、グラスウール455ピッチと割付けが揃う。再利用材を拾いやすい |
| 片流れ・**北高南低** | 落雪を道路（北）側に落とさない。かつ南に深い軒を出せる |
| 南軒の出 900mm | 夏至南中76.9°で南壁を全面日陰、冬至南中30.0°で床の奥まで日射。**かつ軒先Z+3.135が窓上端Z+3.05より高く、眺望が軒で切れない**。この3条件を同時に満たす唯一の値として決めた |
| FL ＝ GL+1,050 | 床下クリアランス0.75m ≧ 設計積雪0.6m。玄関が雪に埋まらない |
| 独立基礎・根入れ1.0m | 想定凍結深度0.9mより深く。凍上対策 |
| コンポストトイレ | 中古便器は寒冷地仕様の壁があるので、**設計で問題ごと回避した** |
| 中古グラスウールは別棟へ | 寒冷地の居室断熱は建物寿命に直結。賭けない |
| 内装は新築現場の石膏ボード端材、目地を見せる | 廃材が**意匠として成立する唯一の場所**。継ぎ目のランダムな割付けを内観の主題にする |
| 主屋の南を伐開 | 浅間方向の視界確保。レンダで木が邪魔だと分かって設計に反映した |
| 外壁 焼杉（黒）＋ガルバ屋根（シルバー） | 寒冷地でメンテフリー寄り、かつCGでコントラストが出る |
